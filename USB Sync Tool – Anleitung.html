macOS App Swift + Python v7.0

USBSync Tool

Professionelle Ordner-Synchronisation vom USB-Stick auf den Mac —
mit nativem UI, Live-Fortschritt, Verlauf, Datumsvergleich und flexiblem Log-Filter

Features

🔍
Ordner-Suche im gesamten Baum

Sucht jeden USB-Ordner rekursiv im gesamten Mac-Verzeichnisbaum — nicht nur direkt im Ziel-Pfad.

🕐
Datumsvergleich

Nur neuere Dateien kopieren: USB-Dateien die älter oder gleich alt wie die Mac-Version sind, werden übersprungen.

🔎
Pfad-Validierung

Beide Pfade werden live geprüft. Start erst möglich wenn beide existieren.

🕐
Pfad-Verlauf

Die letzten 5 Pfade stehen als Dropdown direkt unter dem Eingabefeld zur Auswahl.

📊
Live-Fortschritt

Fortschrittsbalken, 6 Live-Zähler und scrollbares Log in Echtzeit. Spinner wechselt nach Abschluss zu ✅.

☑️
Flexible Log-Filter

Einstellbar welche Aktionen im Log erscheinen: Kopiert, Ersetzt, Übersprungen, Nicht gefunden, Fehler.

❓
Nicht-gefunden-Liste

Ordner/Dateien die auf dem Mac nicht existieren, werden am Ende übersichtlich aufgelistet.

🖱️
Drag & Drop

Ordner direkt aus dem Finder in die Pfad-Felder ziehen.

💾
Persistente Einstellungen

Alle Eingaben und Optionen werden gespeichert und beim nächsten Start vorausgefüllt.

Installation

⚠ Voraussetzungen

macOS 12 Monterey oder neuer · Xcode Command Line Tools · Python 3 (ab macOS 12.3 vorinstalliert)

# Xcode Command Line Tools installieren (falls noch nicht vorhanden)
xcode-select --install

Build-Script herunterladen

Lade build_usb_sync_app.sh herunter (z.B. in den Downloads-Ordner).

Terminal öffnen und ausführen

cd ~/Downloads
chmod +x build_usb_sync_app.sh
./build_usb_sync_app.sh

Das Script kompiliert den Swift-Code und legt USBSync.app auf dem Desktop ab.

Erster Start – Gatekeeper

ℹ Einmalige Bestätigung

Rechtsklick auf USBSync.app → „Öffnen" → im Dialog erneut „Öffnen" klicken. Danach genügt Doppelklick.

Bei Updates: App neu bauen

rm -rf ~/Desktop/USBSync.app
./build_usb_sync_app.sh
ℹ Auf einem anderen Mac

Wenn die App auf einem neuen Mac verwendet wird und der gespeicherte Pfad nicht mehr stimmt, Einstellungen zurücksetzen:

defaults delete de.usbsync.app

Sync-Optionen

OptionBeschreibung
-e Ersetzen Vorhandene Dateien und Ordner auf dem Mac werden durch die Version vom USB-Stick überschrieben. Ohne diese Option werden vorhandene Dateien übersprungen.
-v Log-Datei Eine Log-Datei mit allen Aktionen wird im Root-Verzeichnis des USB-Sticks gespeichert. Dateiname: USBSync_Log_YYYY-MM-DD_HH-MM-SS.txt
-l Löschen Erfolgreich kopierte Dateien und danach leere Ordner werden vom USB-Stick gelöscht. Nur erfolgreich kopierte Elemente werden entfernt.
-n Nicht gefunden kopieren Ordner und Dateien die auf dem Mac nicht gefunden werden, werden direkt in den Mac-Ziel-Pfad kopiert. Ohne diese Option werden sie übersprungen und gemeldet.
-t Nur neuere kopieren Eine Datei wird nur kopiert wenn sie auf dem USB-Stick neuer ist als die vorhandene Mac-Version. Dateien die gleich alt oder älter sind, werden übersprungen und im 🕐-Zähler erfasst.

Sync-Logik

✓ Ablauf

1. Python zählt vorab alle Dateien → Gesamtzahl für den Fortschrittsbalken.
2. Für jeden Top-Level-Eintrag auf dem USB-Stick wird der gesamte Mac-Verzeichnisbaum nach einem gleichnamigen Ordner durchsucht (case-insensitiv, Unicode-normalisiert).
3. Gefundene Ordner: Inhalt wird synchronisiert.
4. Nicht gefundene Ordner:
   → Option -n aktiv: direkt unter Mac-Ziel-Pfad anlegen und kopieren.
   → Ohne -n: überspringen und in der Liste melden.
5. Dateien direkt im USB-Root werden wie nicht gefundene Elemente behandelt.
6. Option -t: vor dem Kopieren Änderungsdatum vergleichen — ältere/gleich alte Dateien überspringen.
7. Option -l: nach dem Kopieren Dateien löschen, dann leere Ordner von unten nach oben.

⚠ Option -l (Löschen)

Nur erfolgreich kopierte Dateien werden gelöscht. Übersprungene und ältere Dateien sowie Ordner mit verbliebenem Inhalt bleiben erhalten. Empfehlung: Option -v (Log) zusammen mit -l aktivieren.

ℹ Option -t (Nur neuere)

Der Vergleich basiert auf dem Änderungsdatum (mtime). Eine Datei wird nur kopiert wenn USB-Datum > Mac-Datum. Bei gleichem Datum wird sie übersprungen. Kombinierbar mit -e: auch vorhandene Dateien werden ersetzt, aber nur wenn die USB-Version neuer ist.

Einstellungen verwalten

# Gespeicherte Einstellungen anzeigen
defaults read de.usbsync.app

# Einstellungen zurücksetzen (z.B. auf neuem Mac)
defaults delete de.usbsync.app

Troubleshooting

„Pfad nicht gefunden" beim Start

Der gespeicherte Pfad vom letzten Mac stimmt nicht mehr. Einstellungen zurücksetzen:
defaults delete de.usbsync.app
Dann neu starten und Pfad per Drag & Drop aus dem Finder einfügen.

Ordner wird nicht gefunden obwohl er existiert

Mögliche Ursache: Unicode-Darstellung des Ordnernamens unterscheidet sich (häufig bei Umlauten). Diagnose mit dem mitgelieferten Script:

python3 usb_sync_diagnose.py "Ordnername" "/Pfad/zum/Mac/Ziel"
App öffnet sich nicht (Gatekeeper)

Rechtsklick auf USBSync.app → „Öffnen" → im Dialog „Öffnen" bestätigen (einmalig).

„Operation not permitted" beim Kopieren

macOS verweigert den Zugriff auf bestimmte Ordner.
Lösung: Systemeinstellungen → Datenschutz & Sicherheit → Festplattenvollzugriff → USBSync.app hinzufügen.

Swift-Kompilierung schlägt fehl

Xcode Command Line Tools fehlen oder sind veraltet.
xcode-select --install
Falls bereits installiert: Systemeinstellungen → Allgemein → Softwareaktualisierung.

ℹ Drag & Drop funktioniert nicht

Ordner direkt aus einem Finder-Fenster in das Textfeld ziehen — nicht vom Desktop-Hintergrund. Alternativ Pfad manuell eintippen oder per Verlauf-Dropdown auswählen.
